# 🤖 Lenguajes Formales, Computabilidad y Autómatas (JFLAP)
* **Materias asociadas:** Lenguajes Formales y Computabilidad, Lógica Simbólica, Programación Lógica.
* **Herramientas:** JFLAP (archivos `.jff`), modelado formal.
* **Enfoque:** Diseño y simulación de Autómatas Finitos Deterministas (AFD) y No Deterministas (AFND), Expresiones Regulares, Gramáticas Libres de Contexto, Autómatas a Pila (AP) y Máquinas de Turing.
