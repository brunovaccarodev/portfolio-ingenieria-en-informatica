# ⚡ Algoritmos Concurrentes y Paralelos (Lenguaje C)
* **Materias asociadas:** Algoritmos Concurrentes y Paralelos, Sistemas Operativos.
* **Lenguaje y Herramientas:** C (GCC), POSIX Threads (`pthread`), llamadas al sistema Unix (`fork`, `pipe`), semáforos y memoria compartida.
* **Enfoque:** Programación concurrente y paralela a bajo nivel, sincronización de procesos e hilos, sección crítica, exclusión mutua (mutex) y prevención de condiciones de carrera y *deadlocks*.
