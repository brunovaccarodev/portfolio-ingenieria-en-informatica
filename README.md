# 📂 Proyectos Asociados a la Carrera - Ingeniería en Informática

Repositorio centralizado que recopila proyectos, prácticas de laboratorio, modelados de sistemas y desarrollos realizados durante mi formación como **Analista Universitario en Sistemas de Computación** y mi carrera de grado en **Ingeniería en Informática**.

---

## 🛠 Stack Tecnológico y Competencias
- **Lenguajes y Paradigmas:** Java (POO), Python, JavaScript, SQL.
- **Desarrollo Web / Frontend:** HTML5, CSS3, JavaScript (ES6+).
- **Bases de Datos:** MySQL y gestión de esquemas relacionales.
- **Ingeniería de Software:** Análisis de Requerimientos, Modelado UML, Arquitectura MVC, Testing y QA.
- **Infraestructura y Redes:** Arquitectura de redes, telecomunicaciones y sistemas críticos.
- **Control de Versiones y Entornos:** Git, GitHub, desarrollo en entornos Linux y macOS (Unix).

## 📁 Estructura del Repositorio

- ### 01. 🗄️ `01-bases-de-datos/`
  Modelado de datos, consultas avanzadas, procedimientos almacenados y optimización en MySQL *(Próximamente)*.

- ### 02. ☕ [`02-programacion-java/`](./02-programacion-java)
  Aplicación de los principios de Programación Orientada a Objetos (POO), patrones de diseño y lógica de negocio eficiente.
  * **Proyecto 1:** [Arquitectura Cliente-Servidor con Sockets TCP](./02-programacion-java/cliente-servidor-sockets) — Comunicación bidireccional en red utilizando `java.net.Socket` y `ServerSocket`.

- ### 03. 🌐 [`03-desarrollo-web/`](./03-desarrollo-web)
  Interfaces interactivas y aplicaciones cliente construidas con HTML, CSS y JavaScript moderno.
  * **Proyecto 2:** [Maquetación Semántica: Perfil Profesional](./03-desarrollo-web/biografia) — Estructura documental HTML5 bajo estándares W3C y accesibilidad.
  * **Proyecto 3:** [Calculadora de Estadísticas en Tiempo Real](./03-desarrollo-web/calculadora-estadisticas) — Lógica en JavaScript (ES6+), métodos funcionales (`reduce`, *spread operator*) y manipulación del DOM.
  * **Proyecto 4:** [Consumo de Servicios Web REST (Fetch API)](./03-desarrollo-web/consumo-servicios-web) — Integración asíncrona mediante peticiones `GET` (Promesas) y `POST` (`async/await`).

- ### 04. 🏗️ `04-sistemas-y-arquitectura/`
  Documentación de análisis de sistemas, diagramas UML y prácticas enfocadas en alta disponibilidad y redes *(Próximamente)*.
