# 📂 Proyectos Asociados a la Carrera - Ingeniería en Informática

Repositorio centralizado (*monorepo*) que recopila proyectos, prácticas de laboratorio, modelados de sistemas y desarrollos realizados durante mi formación como **Analista Universitario en Sistemas de Computación** y mi carrera de grado en **Ingeniería en Informática**.

---

## 🛠 Stack Tecnológico y Competencias
- **Lenguajes y Paradigmas:** Java (POO), C (Programación Concurrente y de Sistemas), Python, JavaScript (ES6+), SQL.
- **Algoritmos, Concurrencia y Computabilidad:** Estructuras de datos avanzadas, hilos y procesos en C (`pthreads`/IPC), modelado de autómatas y gramáticas formales con **JFLAP**.
- **Desarrollo Web / Frontend:** HTML5 Semántico, CSS3, JavaScript moderno, DOM, Fetch API (REST).
- **Bases de Datos:** MySQL, modelado conceptual/lógico (DER), normalización y procedimientos almacenados.
- **Ingeniería de Software y QA:** Ingeniería de Requerimientos (SRS), Modelado UML, Arquitectura MVC, Diseño de Casos de Prueba y Testing.
- **Infraestructura, Redes y SO:** Arquitectura de computadores, administración de Sistemas Operativos (Unix/Linux/macOS/Windows), redes TCP/IP y sistemas de alta disponibilidad.

## 📁 Estructura del Repositorio y Módulos Técnicos

### 01. 🗄️ [`01-bases-de-datos/`](./01-bases-de-datos)
Modelado de datos, diseño relacional y optimización de consultas (*Bases de Datos I*).
* 📐 **[Modelado y Diseño Relacional](./01-bases-de-datos/modelado-y-diseno-relacional):** Diagramas Entidad-Relación (DER) y normalización.
* 💻 **[Consultas y Procedimientos SQL](./01-bases-de-datos/consultas-y-procedimientos-sql):** Scripts DDL/DML, `JOINs`, vistas, *triggers* y *stored procedures*.

### 02. ⚙️ [`02-programacion-y-algoritmos/`](./02-programacion-y-algoritmos)
Desarrollo orientado a objetos en **Java**, concurrencia a bajo nivel en **C**, estructuras de datos y teoría de la computación con **JFLAP**.
* ✔️ **[Proyecto Activo: Arquitectura Cliente-Servidor con Sockets TCP (Java)](./02-programacion-y-algoritmos/cliente-servidor-sockets):** Comunicación bidireccional en red con `java.net.Socket` y `ServerSocket`.
* ☕ **[POO y Estructuras de Datos (Java)](./02-programacion-y-algoritmos/poo-y-estructuras-de-datos-java):** *Programación Orientada a Objetos* y *Algoritmos y Estructuras de Datos I y II* (+ Talleres).
* ⚡ **[Concurrencia y Paralelismo (Lenguaje C)](./02-programacion-y-algoritmos/concurrencia-y-paralelismo-c):** *Algoritmos Concurrentes y Paralelos* (procesos, hilos POSIX, semáforos y sincronización en C).
* 🤖 **[Lenguajes Formales y Autómatas (JFLAP)](./02-programacion-y-algoritmos/lenguajes-formales-y-automatas-jflap):** *Lenguajes Formales y Computabilidad* (AFD, AFND, autómata a pila y máquinas de Turing).

### 03. 🌐 [`03-desarrollo-web/`](./03-desarrollo-web)
Interfaces interactivas, maquetación semántica e integración asíncrona de servicios web.
* ✔️ **[Proyecto Activo: Maquetación Semántica - Perfil Profesional](./03-desarrollo-web/biografia):** Estructura HTML5 bajo estándares de accesibilidad W3C.
* ✔️ **[Proyecto Activo: Calculadora de Estadísticas en Tiempo Real](./03-desarrollo-web/calculadora-estadisticas):** JS (ES6+), métodos funcionales (`reduce`) y aplicación de *Estadística y Probabilidad*.

### 04. 🏗️ [`04-sistemas-y-arquitectura/`](./04-sistemas-y-arquitectura)
Ingeniería de software, aseguramiento de calidad (QA) y fundamentos de infraestructura.

* 🧪 **[Testing y QA](./04-sistemas-y-arquitectura/testing-y-qa):** *Pruebas de Sistemas* (planes de prueba, casos de test de caja blanca/negra y validación).
* 🖥️ **[Sistemas Operativos y Redes](./04-sistemas-y-arquitectura/sistemas-operativos-y-redes):** *Arquitectura del Computador*, *Sistemas Operativos* y *Comunicaciones*.
